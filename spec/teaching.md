# WentianCode — 教学文档制作规范（长期约定）

> 适用：为本项目**每个版本**产出"零基础精讲"教学页时（v0.1、v0.3、v0.4…）。
>
> 本章是教学页的**唯一事实来源**：要改规范，先改本章、再动 HTML。
>
> 本章是**绑定 + 增量**——底座是全局《学习材料制作标准》(`~/.claude/teaching-material-standard.md`)，此处不复述五层细节，只固化 WentianCode 系列的专属约定。两者冲突，以更严的一方为准。
>
> 现存范例：[`../teaching/index.html`](../teaching/index.html)（v0.1 叙事版）、[`../teaching/v0.3-tools.html`](../teaching/v0.3-tools.html)（v0.3 完整五层版，本规范即从它沉淀）。

## 1 · 定位与底线

- 每个版本发布后，产出一篇配套教学页，沉淀"这一版到底在造什么 + 能带走的工程心法"。
- 受众恒定：**非科班、工程基础薄弱**。两条底线不变——① 看了心里真有概念（不是似懂非懂）；② 能带走超越本项目的 insight。
- 教学页属**教学件**：不归档 report-hub；产出后自己截图自检再交付。

## 2 · 五层 → 本系列固定映射

全局标准要求五层齐备。在本系列里，五层固定落成下面这组小节（缺哪层补哪层，宁可多给一层）：

| 全局五层 | 在本系列里怎么落 |
|---|---|
| 1 零基础精讲 | 一节「这版造什么 + 故意**不做**什么」（不做清单本身即工程决策）＋ 一节「N 个新概念，每个先大白话再设计、配生活类比」 |
| 2 真实代码示例 | 一节「真实源码精读」：直接引被学版本的真实 `.py`，删枝节、**逻辑/语义不得改**，每段 6–14 行，关键行高亮 + 箭头 |
| 3 架构全景 | 分层图 ＋ 一次操作的数据流时间线，每步标「住在哪个文件」 |
| 4 工程心法 | 每条配一句**触发口令** ＋ 一行「同一个它出现在哪些行业」（function calling / sudo / 防火墙 / WAL……） |
| 5 测验 | 8 题上下，考设计取舍**不考**字段名/路径/常量；点击展开答案；带甲乙丙丁等第 |

## 3 · 系列视觉系统（跨版本一致，不得每版另起一套）

- 单文件 HTML，中文，走 `frontend-design`。
- **设计令牌**与组件类直接复用 `teaching/index.html` 的 `:root`：朱砂 `--cinnabar:#c7402d` / 纸张 `--paper:#faf6ef` / 墨 `--ink:#1c1a17` / 暗终端 `--term-bg:#16181d` 等。新版不重调色板。
- **字体**：正文 `Noto Serif SC`，等宽 `JetBrains Mono`。不换字体——保持同系列姊妹感。
- 纸张噪点、朱砂选区、入场上浮动画沿用。

## 4 · 组件词汇（复用，不重造）

| 组件（class） | 用途 |
|---|---|
| `.term-window` + `.term-body` | 终端实录（真实交互/测试输出），`.p/.c/.y/.r/.dim/.ok` 着色 |
| `.term-window` + `.code-body` | 源码面板：文件名标题栏 + `PYTHON` 语言徽章 + 语法高亮 span（`.k/.s/.o/.f/.num/.v`）+ 高亮行 `.row.hl` + 行尾箭头 `.arw` |
| `.term`（`<dl>`） | 术语/概念卡（顶部细横条，含生活类比 `.ana`） |
| `.arch` / `.arch-box` / `.arch-arrow` | 分层架构图 |
| `.timeline` / `.tstep` | 步骤/数据流时间线（`.home` 标住在哪个文件） |
| `.law` | 心法卡：大号触发口令 `.cmd` + 行业回响 `.echo .tag` |
| `.quiz`（`<details>`/`<summary>`） | 点击展开测验，无需 JS，`.qn` 题号 + `.ans .pt` 要点 |
| `.checks` / `.nope` / `.plain` | 做到的 ✓ / 不做的 ✕ / 普通列表 |

## 5 · 硬规则（不豁免）

- **禁止左侧竖色条**（全局硬规则）：任何卡片/容器一律不用 `border-left` 彩色竖条；强调改用顶部细横条、阴影、描边、圆点。
- **代码高亮行**：用「整行背景浅染（`rgba(199,64,45,.13)`）＋ 行尾 `←` 箭头注释」，**绝不**用左侧竖色条。
- **源码必须真实**：可删枝节，但逻辑/语义不得改写、不得杜撰。
- **数字与事实**（任务数、工具数、测试数、依赖数、提交数…）取自项目本身，可核，不编。
- **测验只考原理/取舍**，不考路径、字段名、常量数字、API 事件名；评分道理对即给分、术语不精确不扣分。
- 脚本只允许轻量、可降级（如无需 JS 的 `<details>`）；优先 CSS-only。

## 6 · 命名与产出位置

- 文件名：`teaching/v<MAJOR.MINOR>-<topic>.html`（如 `teaching/v0.3-tools.html`）。v0.1 历史文件名 `teaching/index.html` 保留。
- 每篇顶部放一条**回链到上一篇**，保持系列连续。
- 页脚署：版本 + 日期 +「源码/终端输出均取自真实项目」+ 落款印章 `守心火 · 履难事 · 磨心智 · 见异镜`。

## 7 · 验证与交付（完成前铁律）

- 改完 HTML **自己截图自检**（Playwright MCP 或 Chrome CDP），出问题直接修，不等用户提醒。
- **截图陷阱（已踩，记牢）**：本页用 `animation-timeline:view()` 滚动驱动入场 + `scroll-behavior:smooth`。CDP 整页/视口截图易拍到 `opacity:0` 入场帧、或拍错滚动位（拍出白屏）。可靠做法：先注入 `*{animation:none!important;opacity:1!important;transform:none!important}`、关 smooth，再「隔离单节（其余 `display:none`）+ fullpage」分段拍；或对**已在视口内**的元素做 element 截图。白屏先怀疑绘制时序，用 `getComputedStyle` 验 `opacity/visibility` 再下结论。
- 教学件**不归档 report-hub**。
- （可选）同步 `learning-tracker`（OKR + records）。

## 8 · 一份合格教学页的验收清单

- [ ] 五层齐备，且按 §2 映射落到对应小节
- [ ] 视觉令牌 / 字体 / 组件复用自系列，无另起炉灶
- [ ] 源码真实、关键行高亮 + 箭头、**无左侧竖色条**
- [ ] 概念有生活类比；心法有触发口令 + 行业回响
- [ ] 测验考取舍、可展开、带等第
- [ ] 数字事实取自项目、可核
- [ ] 截图自检通过、未归档 report-hub
