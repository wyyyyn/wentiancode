## 三条铁律

1. 四份文档没全部生成并统一审阅通过 → 不动代码。
2. 没有先失败的测试 → 不写生产代码（TDD 红-绿-重构）。
3. 没有当场新鲜证据 → 不许声称"完成"。

## 项目一句话

yuning 自己的命令行 AI 助手（类 Claude Code）。v0.1 = 终端多轮流式对话内核（多后端 + 流式 + thinking + Markdown + 持久化）；v0.2 = Claude Code 式交互（横幅 / 后端选择 / 多行输入框 / 状态栏 / 计时反馈 / Esc 中断）；v0.3 = 工具系统（六核心工具 + 注册中心 + 双协议工具调用 + 单轮执行 + 副作用确认）；v0.4 = Agent Loop（ReAct 多轮循环 + 五停机条件 + 异步事件流解耦 + 只读并发分批 + /plan //do 计划模式）；v0.5 = 结构化系统提示 + 提示词缓存（七模块可插拔系统提示 + 文天人格 + 约定双重强化 + Anthropic cache_control 断点 + `<system-reminder>` 消息通道注入 + 缓存命中可观测）；v0.6 = 权限系统·五层防御（危险命令黑名单 + 路径沙箱 + 可配置规则引擎 + 三层配置合并 + 四档权限模式按类别兜底 + 人在回路三选一；五层逐层短路、判定 Allow/Deny/Ask 三态、判定门在 AgentLoop 编排层、拒绝回灌不中断、Shift+Tab 切档）。详见 `spec.md`。
